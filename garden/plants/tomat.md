# Профиль растения: *Solanum lycopersicum* L., томат (помидор)

- **Дата карточки:** 2026-04-03
- **Зона:** Минская область (Беларусь), есть **парник для овощей**
- **Источники:** [ogorodnik.by — посев и рассада](https://ogorodnik.by/posev-semyan-i-vyrashhivanie-rassady-tomatov/); [ogorodnik.by — посадка и уход в РБ](https://ogorodnik.by/vyrashhivanie-tomatov-v-belarusi-posadka-i-uhod/); ориентиры по срокам посева под тип укрытия — в том числе [magilev.by (2026)](https://magilev.by/news/2026/03/10/kogda-luchshe-vsego-poseyat-semena-tomatov-na-rassadu-chtoby-poluchit-obilnyj-urozhaj-uznali); профилактика фитофторы (в т. ч. народные схемы) — обзоры [belnovosti.by](https://www.belnovosti.by/sad-i-ogorod/kak-borotsya-s-fitoftoroy-na-tomatah-na-zametku-ogorodnikam). Уточняйте дозы и СОЖ по этикетке препарата.

## Кратко
Однолетняя теплолюбивая культура; в Минской области **без рассады или без парника/поздней высадки** короткий сезон и риск **возвратных заморозков** и **фитофторы** в дождливое жаркое лето. Парник позволяет сдвинуть высадку раньше и стабилизировать микроклимат; открытый грунт — после установившегося тепла.

## Рассада: нужна ли и когда
| Вопрос | Ответ |
|--------|--------|
| Выращивать рассаду или сеять в грунт | **Рассада обязательна** для нормального урожая; прямой посев в открытый грунт в РБ обычно уступает по срокам и дружности всходов. |
| Сроки посева (дом/парник) | Зависят от **типа укрытия при высадке** и **срока созревания сорта**. Ориентиры для Беларуси: **обогреваемая плёнка** — конец февраля — ~10 марта; **необогреваемая теплица/тоннель/парник** — **15–25 марта**; под **открытый грунт** — чаще **начало апреля** (или конец марта для ранних низкорослых — по погоде и сроку выхода в грунт). На **подоконнике** без ранней теплицы разумный компромисс — **середина марта** (см. календарь). Возраст рассады к высадке: **~50–55 дней** под открытый грунт, **~55–60 дней** под плёнку/парник (в среднем по рекомендациям для РБ). |
| Сроки пикировки / перевалка | Обычно при **1–2 настоящих листьях**; для томата пикировка типична и полезна для корневой системы. |
| Закалка перед высадкой | **7–10 дней** постепенного выноса на улицу/в парник при дневной температуре; избегать резкого холода и прямого солнца в первые дни. |

## Высадка в грунт (открытый / парник)
- **Ориентировочные даты** для Минской области (с учётом возвратных заморозков):
- **Парник:** **конец мая** (типичный ориентир **~25.05** при стабилизации ночных температур; при сильных похолоданиях — досветка/укрытие агроволокном внутри).
- **Открытый грунт:** **не ранее начала июня** (часто **после 5–10.06**), когда миновала угроза заморозков по местному прогнозу; для низкорослых иногда чуть раньше при тёплой весне — только с контролем погоды.

## Удобрения
| Период | Тип (органика / NPK / микро) | Примечание |
|--------|------------------------------|------------|
| Перед посадкой | Перепревший компост / гумус; фосфорно-калийные (суперфосфат, зола) в лунку по норме грунта | **Не** свежий навоз в непосредственный контакт с корнями. |
| Начало вегетации после укоренения | Слабые настои органики или комплекс **с умеренным азотом** | Перекорм азотом в фазе цветения/завязи даёт буйную зелень в ущерб завязи. |
| Цветение — налив плодов | Калий, фосфор; **кальций** (хелаты, «нитрат кальция», зола в настое) при признаках **вершинной гнили** | Согласовать с общими датами подкормок овощей в календаре (~10.06, ~15.07). |
| Вторая половина лета | Подкормки по состоянию листа и плодов; снижение азота | При признаках перегруза — прекратить стимулирующие подкормки. |

## Защита от вредителей и болезней
| Период | Цель | Препарат / метод (с учётом сроков ожидания до урожая) |
|--------|------|--------------------------------------------------------|
| Ранняя весна в парнике | Пероноспороз, альтернариоз, конденсат | **Проветривание**, не переувлажнять; при необходимости **медьсодержащие** по инструкции (СОЖ до сбора). |
| Вся вегетация | Колорадский жук (если рядом картофель) | Сбор яиц/личинок, **инсектициды** из разрешённого перечня — только по этикетке и СОЖ. |
| Июль — август | **Фитофтора**, макроспориоз | Избегать полива по листу; мульча; удаление **нижней** листвы для проветривания; **чередование** профилактических опрыскиваний (медь, биопрепараты, схемы с молочно-йодными или зольными настоями — как дополнение к режиму, не вместо санации при вспышке). |
| Парник | Белокрылка, паутинный клещ | Раннее обнаружение липкими ловушками; био/химия по необходимости с учётом СОЖ. |

## Прочие работы
- **Полив:** регулярный **под корень**, в жару чаще; в дождливую погоду и при риске грибков — умеренно, без переувлажнения.
- **Мульча:** солома/сено — снижает всплески влаги на плодах и брызги с почвы.
- **Подвязка и формировка:** для **индетерминантных** — 1–2 стебля, пасынкование; для **детерминантных** — по сорту (часто ограниченное пасынкование или кустовая схема).
- **Уборка:** срыв в фазе технической/биологической зрелости в зависимости от назначения; **зелёные** при угрозе заморозков — дозаривание.
